Create a premium, modern, cinematic Nature website called **WILDORA — Into The Wild**.

### Design

* Luxury dark-green nature theme
* High-quality cinematic mountain, forest, ocean and wildlife imagery
* Modern glassmorphism elements
* Premium typography
* Strong visual hierarchy
* Smooth and attractive UI
* Responsive design for desktop, tablet and mobile
* Website should feel like a professional nature/travel brand website

### Animation

Make the website highly animated but still premium and smooth.

Use **CSS animations only**:

* Hero background slow cinematic zoom
* Hero text reveal animation
* Navbar slide-down animation
* Floating glass card
* Floating glowing orbs
* Moving light effects
* Glowing green text
* Pulsing CTA buttons
* Image zoom on hover
* Nature cards lift and slightly rotate on hover
* Card content moves upward on hover
* Statistics pulse animation
* Quote floating animation
* CTA background zoom animation
* Smooth hover transitions
* Subtle glowing effects
* Animations should feel natural, not childish or excessive

### Technical Requirements

* Use **HTML5 + CSS3 only**
* **NO JavaScript**
* Keep HTML and CSS in separate files:

  * `index.html`
  * `style.css`
* Use clean, beginner-friendly code
* Use CSS Grid and Flexbox
* Add responsive media queries
* Make the website visually impressive and professional
* Do not use unnecessary libraries or frameworks
* Code should work directly after opening `index.html`
